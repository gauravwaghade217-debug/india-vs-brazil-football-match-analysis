# India vs Brazil – Football Match Analysis 🇮🇳🇧🇷

## 📌 Project Overview
This is an independent football performance analysis project based on the India vs Brazil match played on 3 October 2026.

The objective of this project is to analyse match events, understand tactical patterns, evaluate player information, and identify potential areas for improvement.

## 🎯 Project Objectives
- Analyse important match events using timestamps.
- Understand attacking and defensive patterns.
- Identify key moments and tactical observations.
- Present match and player information through a Power BI dashboard.
- Convert match observations into practical coaching recommendations.

## 🛠️ Tools Used
- Microsoft Excel
- Microsoft Power BI
- Manual Match Analysis

## 📂 Project Files

### 1. Excel Match Analysis
Contains timestamp-based match events, observations, and tactical interpretations.

### 2. Power BI Dashboard
An interactive dashboard displaying match statistics and player information. Selecting a player displays the logo of their current club.

### 3. Match Analysis Report
A report covering tactical observations, important match moments, strengths, areas for improvement, and potential coaching recommendations.

### 4. Dashboard Screenshots
Visual previews of the Power BI dashboard and selected analysis findings.

## ⚽ Key Areas Analysed
- Attacking transitions and counterattacks
- Defensive organisation
- Pressing and ball recovery
- Wide attacks and crossing
- Important match events
- Player and team information
